# MCP Controller (Factorio mod)

This folder follows the canonical Factorio mod layout described in the [official mod structure docs](https://lua-api.factorio.com/latest/auxiliary/mod-structure.html):

- `info.json` — metadata (name/version/Factorio version/dependencies).
- `control.lua` — runtime script for command handling.

To install, zip the folder contents (or copy the directory) into your server's `mods/` directory using the standard `name_version.zip` naming convention (e.g., `mcp-controller_0.1.0.zip`).
